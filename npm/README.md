# Stranger Quarkdown

Markdown preprocessing automation for Svelte/Kit projects.

Please visit [the GitHub](https://github.com/Sup2point0/stranger-quarkdown#readme) for the full README :]


<br>


## Quickstart

Run:

```bash
> npx squarkdown
```

With extras:

```bash
> npx squarkdown --assets --fonts
```

Remind yourself:

```bash
> npx squarkdown --help
```
